# Luxury Decor Home

Sitio web premium para Luxury Decor Home, showroom de revestimientos, wallpapers y decoración en República Dominicana.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Luego abre `http://localhost:3000`.

## Assets

Las imágenes actuales están centralizadas en `lib/content.ts` y pueden reemplazarse progresivamente por archivos reales en:

- `public/brand`
- `public/products`
- `public/showroom`
- `public/inspiration`

Los enlaces de WhatsApp usan el número temporal `10000000000`.
